# 🚀 حذيفة أحمد الميكي — الموقع الشخصي

موقع شخصي احترافي لعرض ملف الأعمال والسيرة الذاتية.

## 📁 هيكل الملفات

```
hothifa-portfolio/
│
├── index.html              ← الصفحة الرئيسية
│
├── css/
│   ├── reset.css           ← إعادة ضبط الأنماط الأساسية
│   ├── variables.css       ← متغيرات التصميم (ألوان، خطوط...)
│   ├── layout.css          ← التخطيط العام والشبكات
│   ├── components.css      ← مكونات الواجهة (بطاقات، أزرار...)
│   ├── animations.css      ← الرسوم المتحركة والتأثيرات
│   └── responsive.css      ← التجاوب مع الشاشات
│
├── js/
│   ├── data.js             ← بيانات المشاريع والمحتوى
│   ├── utils.js            ← دوال مساعدة
│   ├── animations.js       ← منطق الحركات والتأثيرات
│   ├── projects.js         ← إدارة المشاريع (إضافة، عرض، تصفية)
│   └── main.js             ← التهيئة الرئيسية للصفحة
│
├── images/                 ← مجلد الصور (أضف صورك هنا)
└── projects/               ← ملفات إضافية للمشاريع
```

## ✨ المميزات

- **تصميم احترافي** بألوان داكنة أنيقة مع تأثيرات Glow زرقاء
- **رفع الصور**: يمكن رفع صورك الشخصية وصور المشاريع مباشرة من المتصفح
- **إضافة مشاريع**: زر "إضافة مشروع" لإضافة مشاريع جديدة دون تعديل الكود
- **تصفية المشاريع**: تصفية حسب النوع (ويب / موبايل / تصميم)
- **رسوم متحركة**: تأثيرات انزلاق عند التمرير وأرقام متحركة
- **نص متحرك**: عبارات احترافية متغيرة في الهيرو
- **متجاوب**: يعمل على جميع أحجام الشاشات
- **تخزين محلي**: الصور المرفوعة تُحفظ في المتصفح

## 🖼️ كيفية رفع الصور

### الصورة الشخصية
- اضغط على أيقونة الكاميرا (📷) فوق الصورة في القسم الرئيسي

### صور المشاريع
- اضغط على أيقونة الكاميرا الصغيرة في كل بطاقة مشروع

### إضافة مشروع جديد
- اضغط على بطاقة "أضف مشروعاً جديداً" في آخر المشاريع
- أملأ النموذج وأضف صورة للمشروع

## 🎨 تخصيص الألوان

افتح `css/variables.css` وعدّل المتغيرات:

```css
--primary: #0ea5e9;    /* اللون الأساسي */
--accent: #f59e0b;     /* لون التمييز */
```

## 📝 إضافة مشروع جديد في الكود

افتح `js/data.js` وأضف كائناً جديداً في مصفوفة `PROJECTS_DATA`:

```js
{
  id: 6,
  title: 'اسم المشروع',
  desc: 'وصف المشروع',
  tags: ['Laravel', 'Flutter'],
  category: 'web',     // web | mobile | design
  icon: 'fa-code',
  year: '2025',
  highlights: ['ميزة 1', 'ميزة 2'],
  url: 'https://...',  // اختياري
}
```
